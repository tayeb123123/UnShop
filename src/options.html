UnShop

Settings

UnShop learns what you want from what you reject on Amazon, eBay, Walmart, Target and Best Buy search pages. An AI model (Claude by default, or OpenAI, Gemini, or a local Ollama model) interprets your feedback through a small server you run; without it, simple local rules still work.

Start the server from the project folder:

npm install
cp .env.example .env   # choose a provider, add its key
npm run server

The provider is chosen with LLM_PROVIDER in .env (anthropic, openai, gemini, or ollama). Your API key stays in the server process — it is never stored in the extension. What gets sent: your typed requests, rejection reasons and notes, and the titles and prices of products visible on the page. No account data, reviews, or browsing history.

Your data

Preferences are stored in Chrome’s local extension storage on this device. Each search on each store keeps its own (the 30 most recent; word order and plurals don’t matter), and a new search starts fresh. For a similar search, UnShop offers to reuse what you said, only if you agree. Following UnShop’s refined-search link carries them over.

Unofficial prototype, not affiliated with Amazon, eBay, Walmart, Target or Best Buy. Page layouts change; unknown product attributes are treated as unknown.
