UnShop learns what you want from what you reject on Amazon search pages. Claude interprets your feedback through a small server you run; without it, simple local rules still work.

Claude interpretation

Checking…

Start the server from the project folder:

npm install
ANTHROPIC_API_KEY=sk-ant-… npm run server

Your API key stays in the server process — it is never stored in the extension. What gets sent: your typed requests, rejection reasons and notes, and the titles and prices of products visible on the page. No account data, reviews, or browsing history.

Your data

Each Amazon search keeps its own preferences (the 30 most recent), stored in Chrome’s local extension storage on this device. A new search starts fresh; following UnShop’s refined-search link carries them over.
